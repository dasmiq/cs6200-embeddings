# CS6200 / CS4220: Embeddings

After cloning this repository, you can edit the Jupyter notebook locally or an a hosted platform like Google Colab. Read through the notebooks `embeddings.ipynb`, filling in code and explanations in the blocks starting with "TODO". There are some questions at the end that are required for students in CS6200 and extra credit for students in CS4220.

Whenever you'd like to save your work, and when you are done, make sure to check in and push to GitHub (if working locally) or, in Colab, select "Save a copy to GitHub" or "Save a copy in Drive". You can then submit the ipynb file on Canvas.
